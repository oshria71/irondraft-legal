התחברות (רשות)

ההתחברות אף פעם אינה חובה כדי לשחק. היא נדרשת רק אם תרצו שהשיאים, המטבעות והסטטיסטיקות שלכם יישמרו בחשבון ויהיו זמינים במכשירים אחרים.

אם תבחרו להתחבר עם Google או Apple, נקבל מהספק: מזהה חשבון ייחודי, את כתובת הדוא״ל שלכם (ב-Apple אפשר לבחור כתובת ממסר פרטית), ואם הספק משתף אותם, גם את שמכם ותמונת הפרופיל. נשתמש בהם רק כדי ליצור ולאבטח את החשבון, להציג את הפרופיל ולאפשר התחברות מחדש במכשירים אחרים. לעולם איננו מקבלים את הסיסמה שלכם ל-Google או ל-Apple. מדיניות הפרטיות של הספק חלה על החלק שלו, ואפשר לבטל את הגישה שלנו בכל עת בהגדרות חשבון ה-Google או ה-Apple.

עם חשבון נשמור גם את נתוני המשחק שלכם: דראפטים, בחירות, תוצאות מערכות, שיאים, יתרת מטבעות והישגים.

אם תשחקו PvP, שחקנים אחרים יראו את השם שלכם בטבלה (כברירת מחדל השם הפרטי מפרופיל ה-Google; אפשר לשנות אותו במשחק), את הצבא השמור, את המדינות שקיבלתם באותו שבוע, את הדירוג ואת מאזן הניצחונות וההפסדים. תוצאות קרבות ומקומות שבועיים נשמרים גם אחרי שהשבוע מסתיים כדי שאפשר יהיה לבדוק את הפרסים.

אפשר לשנות את הבחירות בכל עת דרך הגדרות פרטיות במשחק. המשחק אינו מגיב כרגע לאותות "Do Not Track" של הדפדפן; הבחירות שלכם במשחק חלות במקומם.
